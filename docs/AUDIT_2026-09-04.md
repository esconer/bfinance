## Suggested fix order

1. **Stop fabricating** (N-01…N-09 + B-03): return `None`/omit instead of synthetic values; flag estimates explicitly. Single highest-leverage change — finengine quarantines fall away.
2. **Fix money math** (N-10…N-19 + B-01/B-02): beginning-assets basis, real debt ratios, cash in EV, CFO−Capex FCF, NaN guards.
3. **Screen truth-in-naming** (N-20…N-23 + B-05): enforce what names claim or rename.
4. **Global pacing + retry scope** (N-43/N-44): one shared rate limiter, respect `Retry-After`, retry 5xx — directly relieves finengine's 429 stalls.
5. **Cache hardening** (N-42): WAL + busy_timeout + per-key locks + schema version.
6. **Parity or honesty** (N-24…N-35 + B-06): either match yfinance shapes or document divergence in `YFINANCE_MIGRATION_GUIDE.md`.
7. **Test isolation** (P1 §): record cassettes, fix `:memory:` fixture, gate live tests in CI.
8. **Release hygiene** (B-07): keep PyPI in step with the checkout — on 2026-09-04
   the registry lagged the checkout (0.1.0 vs 0.1.2) until it was re-resolved;
   run `uv lock --upgrade-package bfinance` downstream after every release.
